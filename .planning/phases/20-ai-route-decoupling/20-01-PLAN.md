<task type="auto">
  <name>Task 2: Refactor Route Modules</name>
  <files>routes/ai_routes.py, routes/dl_routes.py, routes/inventory_routes.py, routes/workflow_routes.py</files>
  <action>
    For each file:
    1. Update imports: 
       - Ensure `current_app` is imported from `flask`.
       - Ensure `current_user` is imported from `flask_login`.
    2. Remove the `_app_module()` function definition.
    3. Global search and replace (within each module):
       - `_app_module().db_manager` -> `current_app.extensions['database']`
       - `_app_module().ai_chat_service` -> `current_app.extensions['ai_chat_service']`
       - `_app_module().workflow_service` -> `current_app.extensions['workflow_service']`
       - `_app_module().automation_engine` -> `current_app.extensions['automation_engine']`
       - `_app_module().current_user` -> `current_user`
       - `app_module.db_manager` -> `current_app.extensions['database']` (if variable assignment was used)
       - `app_module.db` -> `current_app.extensions['database']`
       - `app_module.workflow_service` -> `current_app.extensions['workflow_service']`
       - `app_module.current_user` -> `current_user`
    4. Remove any remaining `import app` statements inside functions.
  </action>
  <verify>
    <automated>grep -r "_app_module" routes/ | grep -v "__pycache__" | wc -l | grep "^0$"</automated>
  </verify>
  <done>All route modules are decoupled from the app module.</done>
</task>

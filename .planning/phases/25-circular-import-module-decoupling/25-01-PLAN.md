<objective>
Remove the three module-level anti-patterns that cause import side effects and path pollution:

1. `app.py` line 243 — `app = create_app()` executes at import time, spinning up the server any time another module does `import app`.
2. `wsgi.py` is missing — gunicorn has no clean entry point.
3. `core/services/dl_client.py` lines 6-10 — `sys.path.insert` executes at import time, mutating the interpreter path silently; `use_local=True` default forces all callers into in-process DL mode regardless of environment.

Purpose: Make the module graph importable without side effects so future phases (26-28) can freely import from app without triggering server startup or path mutation. Required by CIRC-01, CIRC-02, CIRC-03, NFR-TD-01, NFR-TD-02.

Output: Three clean files — app.py with guarded instantiation, new wsgi.py, and dl_client.py with HTTP-first default and no module-level sys.path code.
</objective>

### 2. Optimize Workflow Engine (Kahn's Algorithm)
- **File:** `core/workflow_engine.py`
- **Action:** Refactor Kahn's algorithm implementation to use `collections.deque`.
- **Implementation:**
  - Import `deque` from `collections`.
  - Replace `pop(0)` calls on lists with `popleft()` on a `deque`. This improves performance from $O(n)$ to $O(1)$ for each removal from the front of the queue.
- **Commit:** `perf(23-01): use collections.deque for workflow engine queue`

- **Commit:** `perf(23-01): optimize invoice service history with deque(maxlen=50)`

# Railway/Nixpacks-style zero-config builds copy requirements.txt alone into

# reference to a sibling file resolves to a nonexistent path inside the build
# container ("Could not open requirements file: ... requirements-base.txt")
# even though the file exists fine locally and in git. A single self-contained
# file is immune to that build-copy-order issue regardless of build system.
